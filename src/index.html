о проекте

кто мы такие

«Цветочный» — учебный проект, онлайн-медиа для всех желающих заботиться о комнатных растениях. Мы собираем понятные гайды по уходу за комнатными цветами, чеклисты, идеи озелениния интерьера, тесты для проверки знаний и готовим словарь с непонятной терминологией.
